# Audio Sims Downloads

Repositório de distribuição beta do Audio Sims: Alternative Life. Nenhum código-fonte ou dado do servidor do jogo pertence a este histórico.

Baixe `AudioSimsSetup.exe` na [release mais recente](https://github.com/joaomariano2014/audio-sims-downloads/releases/latest). O instalador baixa separadamente o aplicativo e os sons, mostra o progresso e permite continuar downloads interrompidos. A pasta padrão é `C:\nostalgames\audio_sims`. Depois da instalação, execute o mesmo instalador na pasta do jogo para verificar e aplicar atualizações.

Os pacotes de aplicativo e sons estão anexados às releases de componentes. Não é necessário extrair os ZIPs manualmente.

Os avisos e atribuições de bibliotecas de terceiros ainda estão sendo reunidos e serão incluídos em uma atualização da distribuição beta.
